# 새 사이트 이전 규칙 (옛 서버 → redesign)

옛 뉴스더힐 서버(미소사 솔루션, 49.247.6.63, 하남시민뉴스와 같은 서버)에서 글을 가져올 때 지키는 규칙이다. 처음 작성 2026-10-17, 교수님 16:13·16:17 지시.

## 1. 가져오지 않는 글
1. **하남시민뉴스 기사는 모두 뺀다.** 아래 2절 판별 기준 가운데 하나라도 확실히 해당하면 가져오지 않는다.
2. **2025-11-27(뉴스더힐 등록일) 이전에 날짜가 찍힌 기사는 가져오지 않는다.** 날짜는 원문 입력일(front matter date) 기준이며, 2025-11-27 당일 기사는 가져온다. 칼럼(오피니언, 최경집 교수의 시선 등)은 바로 빼지 말고 목록을 만들어 교수님께 여쭌다.
3. 애매한 글은 가져오지도 지우지도 않고 **'확인 필요' 목록**에 모은다. 뉴스더힐봇·claude -p·codex exec 세 판단이 모두 '하남시민뉴스 기사'로 일치할 때만 제외를 확정한다. 하나라도 다르면 '확인 필요'로 둔다.
4. 가져온 기사에서 하남시민뉴스 사진만 섞여 있으면 그 사진만 빼고, 본문 끝에 `※ YYYY년 M월 D일 수정: …사진을 뺐다.`를 붙인다.
5. 하남시민뉴스 기사에만 쓰인 이미지는 가져오지 않는다. 다른 뉴스더힐 기사도 같이 쓰는 이미지는 남긴다.

## 2. 하남시민뉴스 판별 기준
| # | 기준 | 확인 방법 |
|---|---|---|
| ① | 출처 표기: 본문·캡션·front matter·원문 HTML에 `하남시민뉴스`, `[하남시민뉴스]`, `hanamsiminnews`가 있다 | `rg '하남시민|hanamsiminnews'` |
| ② | 바이라인: 하남시민뉴스 기자·필자다(홍경선, 김기윤 변호사, 권영명 세무사, 김부성, 김병구 등. 명단은 /workspace/loop/week-2026-W42/newsthehill-hanam-screening.md와 dc2332a 참고) | author 필드와 본문 끝 기자명 |
| ③ | 원문 일치: hanamsiminnews.co.kr(m. 포함)에 같은 제목이나 같은 첫 문장의 글이 있다. 하남 사이트 NewsNo는 뉴스더힐과 따로 매겨지므로 번호가 같다고 같은 글은 아니다 | 제목·첫 문장 웹 검색, `m.hanamsiminnews.co.kr/Front/View?MenuNo=1000000&NewsNo=…` |

- 예외: 한궁 08-23(세계한궁협회 보도자료로 전면 재작성)은 이 규칙 대상이 아니다. 한궁대회 09-08과 최만수 관련 08-13·10-06은 하남시민뉴스 근거가 있을 때만 대상이 된다.
