# Canva 뉴스 카드 (사진이 없는 보도자료 기사의 대표 이미지)

처음 작성 2026-10-28. 교수님 지시: 자체 인포그래픽이 "너무 똑같고", 3D 일러스트는 "너무 AI스러워" → "canva로 하는 게 낫지", 후보 3종을 보고 "이런 게 낫지 … 다른 건 다 맘에 들어"(행사형은 음식 사진이 안 어울린다 → "박람회잖아" → 전시장 사진으로 교체, 10:02 "그래 이렇게 가자").

공통: 크기 YouTube Thumbnail(1280×720), 오른쪽 위 `NEWS THE HILL`, 아래 띠 `자료: ○○ · 그래픽=뉴스더힐`, 무료 요소만.

## 2. 만드는 법 (기사 1건마다)
1. Canva `create-design`(format `YouTube Thumbnail`)에 brief를 쓴다. 형식 이름, 색, 문구를 위 견본처럼 하나하나 적는다. 사진은 기사 주제에 맞게 고르되 **사진 속에 글자·간판·가격표·로고가 없게** 적는다(가짜 정보가 사진에 들어가지 않게). 행사 기사에 음식 사진처럼 안 어울리는 사진을 쓰지 않는다.
2. 완료되면 `read-design`(design_content, thumbnails)으로 **글자를 원문과 한 자씩 대조**하고 미리보기를 본다. 틀리면 `read-design open_transaction` → `edit-design find_and_replace_text` → commit, 또는 다시 생성.
3. `export-design` jpg, quality 90, width 1200.
4. 내보낸 주소는 작업 컨테이너에서 못 받는다(프록시 403). Claude in Chrome('직장' 프로필)으로 옮긴다: 새 탭에서 내보낸 주소를 열고 그 탭에서 `fetch(location.href)` → canvas로 1200×675 JPEG → docs/songpa-auto-publish.md 3절의 GitHub 업로드 방법(버튼 클릭으로 업로드 창 열기 → postMessage)으로 `static/img/news-…-card.jpg` 커밋.
5. 기사 캡션: `*그래픽=뉴스더힐(자료: ○○). 배경 사진은 AI로 만든 이미지입니다.*` (회수 기사는 `제품 사진은 AI로 만든 이미지로, 실제 회수 제품과 다를 수 있습니다.`) — Canva가 만든 사진은 실제 현장 사진이 아니므로 반드시 밝힌다.
