# 경기도 보도자료 자동 게시 절차

처음 작성 2026-10-22. 교수님 지시: 지자체 중 사진까지 자유롭게 쓸 수 있는 곳을 찾아 "경기도" 추가. 검증·배포 원칙은 docs/songpa-auto-publish.md 5~7절과 같다.

## 1. 출처와 이용 조건
- 목록 세 곳(2026-10-22 교수님 지시로 ②③ 추가: "식품 농수산 기관을 많이"):
  1. 경기도 보도자료: `https://gnews.gg.go.kr/briefing/brief_gongbo.do`
  2. **공공기관 보도자료**(경기도 산하기관): `https://gnews.gg.go.kr/briefing/brief_ggi.do` — 경기도농수산진흥원·농업기술원 등 식품·농수산 기관 글을 가장 먼저 본다.
  3. **시군 보도자료**: `https://gnews.gg.go.kr/briefing/brief_sigun.do` — 시군 농업재단·농업기술센터·먹거리·로컬푸드·전통시장 소식 위주.
- 상세는 목록의 `brief_gongbo_view.do?BS_CODE=…&number=…` 링크. RSS·API도 있음(사이트 하단 'RSS 소개', 'API 가이드').
- **시군 보도자료 예외(원저작자 조건 우선)**: 포털 글에 1유형 표시가 있어도 원래 시청이 더 엄격한 조건을 둔 시는 쓰지 않는다 — **성남시(미부착·사전협의), 하남시·구리시(4유형), 광주시(표시 없음)**. 성남·하남은 docs/region-auto-publish.md(보류 중, 두 시 공보팀 메일 등록 뒤 재개)로만 다룬다. 교수님이 따로 풀기 전까지 이 네 시는 시군 게시판에서도 건너뛴다.
- 상세 페이지 끝에 **"위 기사는 공공누리 제1유형:출처표시 조건에 따라 이용할 수 있습니다"**가 있는지 확인한다. 1유형이면 문장 변형·상업적 이용 가능, 출처 표시 필수.
- 1유형 표시가 없는 글은 쓰지 않는다.
- 비교 조사(2026-10-22): 서울시·하남시·구리시는 공공누리 제4유형, 성남시·광주시는 표시 없음 → 쓰지 않는다. 강동구·성동구·용인시는 1유형(교수님이 이번엔 경기도만 선택).

## 2. 이미지
- 본문에 들어간 사진·그래픽(이미지 alt가 '이미지설명'인 큰 이미지)이나 첨부 사진을 쓴다. 캡션 끝은 보도자료를 낸 곳으로: `사진=경기도 제공`, `사진=경기도농수산진흥원 제공`, `사진=포천시 제공` 등(그래픽이면 `그래픽=…`).
- **고립·은둔 청소년, 아동, 환자 등 취약 당사자의 얼굴이 크게 나온 사진은 피하고** 전경·뒷모습·현장 사진을 고른다. 누구인지 보도자료에 없는 인물을 이름으로 지목하지 않는다.
- 이미지가 없으면 `scripts/make_info_card.py` 인포카드.
- 올리는 방법: docs/songpa-auto-publish.md 3절(gnews 탭에서 이미지 fetch → 임시 버튼 클릭으로 GitHub 업로드 창 열기 → postMessage → 커밋). 여러 글을 오가면 window 변수가 사라지므로 `sessionStorage`에 base64를 잠시 저장해 둔다.

## 3. 고르는 기준
- 1순위: **식품·농업·농수산·먹거리·로컬푸드·유통·소상공인**(→ section food). 공공기관·시군 게시판의 식품·농수산 기관 글을 먼저 고른다.
- 2순위: 용인·과천 등 **뉴스더힐 권역 관련**, 도민 생활에 쓸모 있는 단속·지원·모집·제도(→ local)
- 시군 게시판의 단순 기부·성금 기탁, 주민자치회·부녀회 봉사, 홍보대사 위촉, 강연 성황 같은 동네 미담·동정은 뺀다.
- 제외: 도지사 동정·간담회·서면 브리핑, 해외 투자유치 행사, 연구원 정책 제안, 방역 현황 수치 업데이트(ASF 등 정례), 내부 교육
- 한 번에 최대 5건(세 게시판 합계, 2026-10-22 3건→5건).
- 이미 쓴 글은 다시 쓰지 않는다.

## 4. 기사 쓰기
- 모범: `articles/2026-10-22-news-2026102200015.md`(단속, 그래픽), `…00016.md`(먹거리, 사진).
- front matter: `author: 뉴스더힐 편집국`(교수님 10/22 지시: 보도자료 기사는 편집국 명의, 칼럼만 최경집), `section: local`(먹거리·유통은 `food`), `time`은 게시 시각.
- 1유형이라 문장을 다듬어 써도 되지만, 인용문은 원문 그대로 자르지 않는다. 보도자료에 없는 평가를 덧붙이지 않는다.
- 기사 끝: `※ 이 기사는 경기도 보도자료(경기도뉴스포털, 공공누리 제1유형·출처표시)를 바탕으로 작성했습니다. 사진은 경기도가 보도자료와 함께 제공한 것입니다.` 공공기관·시군 글이면 '경기도' 자리에 기관명·시군명을 쓴다(예: `※ 이 기사는 포천시 보도자료(경기도뉴스포털 시군 보도자료, 공공누리 제1유형·출처표시)를 바탕으로 작성했습니다.`).
