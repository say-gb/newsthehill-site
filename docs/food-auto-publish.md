# 식품·유통 기사 자동 게시 절차 (정부 보도자료)

처음 작성 2026-10-22. 교수님 지시: "식품 유통 뉴스 받아올 수 있는 곳 찾아서 하자". 송파구 절차(docs/songpa-auto-publish.md)와 같은 원칙(검증 후 게시)을 따른다.

## 1. 출처와 이용 조건
| 출처 | 받는 곳 | 이용 조건 |
|---|---|---|
| 농림축산식품부 보도자료 | RSS `https://www.mafra.go.kr/bbs/home/792/rssList.do?row=50`, 본문은 각 글 페이지(`.../bbs/home/792/{번호}/artclView.do`)에 텍스트로 있음 | 글 하단 "공공누리 출처표시 조건" 표시 확인. 저작권법 제24조의2 |
| 식품의약품안전처 보도자료 | RSS `https://www.mfds.go.kr/www/rss/brd.do?brdId=ntc0021`(제목만). 본문은 정책브리핑(korea.kr) 같은 제목 글의 PDF 바로보기(`/common/docViewer.do?...`)에서 읽음 | 정책브리핑: "텍스트에 한하여 공공누리 제1유형" |

- **이미지 규칙 (교수님 10/22 11:3x 결정: 부처 제공 사진 + 없으면 자체 인포카드)**
  1. 농식품부·식약처 **보도자료 글에 첨부된 현장 사진**(jpg, 사진 zip)은 쓸 수 있다. 캡션 끝에 `사진=농림축산식품부 제공` 식으로 적고, 기사 끝 출처 문장에 "사진은 ○○가 보도자료와 함께 제공한 것"을 덧붙인다. 누구인지 보도자료에 없는 인물을 이름으로 지목하지 않는다.
  2. 정책브리핑(korea.kr) 정책뉴스·멀티미디어 사진, 연합뉴스·통로이미지 사진, 카드뉴스 이미지는 **쓰지 않는다**(저작권자 허락 필요).
  3. 쓸 사진이 없으면 `scripts/make_info_card.py`로 **자체 인포카드**를 만든다(1200×675, 뉴스더힐 네이비·골드). 핵심 수치 2~4줄, 하단 `자료: ○○`. 파일명 `static/img/news-…-card.jpg`, 캡션 `*그래픽=뉴스더힐(자료: ○○)*`. 카드 숫자도 원문과 대조한다.
  4. 사진 올리기: 브라우저에서 사진(또는 zip)을 받아 GitHub 업로드 화면으로 넘긴다(docs/songpa-auto-publish.md 3절 방법. zip은 페이지 안에서 central directory를 읽고 `DecompressionStream('deflate-raw')`로 풀어 가로 1200px JPEG로 줄인다). 브라우저를 못 쓰면 인포카드만 쓴다.
- 기사 끝에 출처 문장을 반드시 넣는다. 예: `※ 이 기사는 농림축산식품부 보도자료(공공누리 제1유형, 출처표시)를 바탕으로 작성했습니다.`
- mfds.go.kr은 Claude in Chrome 사이트 허용이 안 돼 있을 수 있다. 그러면 korea.kr로 읽는다.

## 2. 고르는 기준
- 대상: 식품·농축수산물의 유통, 가격·수급, 원산지, 수출입, 식품 안전(회수·판매중단·위해), 외식·식품산업, 전통식품·급식, 플랫폼·온라인 판매 제도
- 제외: 농촌 교통·복지, 농지 행정, 비료·농기계 지원, 인사·행사 일정만 있는 글, 의약품·의료기기·화장품(식약처)
- 한 번에 최대 4건. 회수·판매중단 같은 소비자 안전 소식을 먼저 고른다.
- 이미 쓴 글은 다시 쓰지 않는다: `articles/`에서 제목 핵심어로 `rg`해 확인.

## 3. 엠바고(보도 시점) 지키기
- 농식품부 RSS에는 엠바고 전 글도 올라온다. 첨부파일 이름의 `(10. 21. 15시부터)` 같은 표기나 글 페이지의 시각을 확인해, **그 시각이 지나지 않았으면 쓰지 않는다**(다음 실행 때 처리).
- 식약처 자료는 PDF 첫 줄 "보도시점"을 확인한다.

## 4. 기사 쓰기
- 파일: `articles/YYYY-MM-DD-news-YYYYMMDDNNNNN.md`, `section: food`, `author: 최경집`, `time`은 게시 시각(현재 시각보다 뒤로 두지 않는다).
- 모범: `articles/2026-10-22-news-2026102200003.md`~`…00006.md`(00004는 부처 제공 사진, 나머지는 인포카드).
- 리드는 독자(소비자·판매자·업계)에게 무엇이 달라지는지부터. 보도자료 문장을 그대로 붙이지 않고 다시 쓴다. 인용문은 원문 그대로, 잘라 쓰지 않는다.
- 회수 기사는 `## 회수 대상`(업체·제품명·소비기한·용량), `## 소비자 행동 요령` 형식.
- 보도자료에 없는 평가·설명(예: 물질의 위험성 등급)을 덧붙이지 않는다. 계산한 수치는 `(본지 계산)` 표시.
