처음 작성 2026-10-28. 교수님 지시: "클라우드에서 경기도 식품 유통을 다 넣으면 안 되나" → 예약 작업 하나로 세 출처를 한 번에 처리한다. PC 없이 클라우드에서 돈다.
예약 작업이 이 문서를 읽고 그대로 따른다. 출처별 세부 규칙은 각 문서가 기준이다.

## 0. 순서 (한 회차)
1. 준비: 저장소 클론, `git fetch` 후 최신 redesign 기준으로 작업.
2. **송파구** — docs/songpa-auto-publish.md 전체(메일 Gmail 커넥터, 사진 3-0·3-A·3-B, 라벨).
3. **식품·유통** — docs/food-auto-publish.md + docs/canva-card.md (농식품부·식약처, 한 번에 최대 4건, 엠바고 확인).
4. **경기도** — docs/gyeonggi-auto-publish.md + docs/canva-card.md (본청·공공기관·시군 게시판, 공공누리 1유형만, 성남·하남·구리·광주 제외, 한 번에 최대 5건).
5. 세 출처에서 쓴 기사를 **한 번에 검증·빌드·배포**한다(docs/songpa-auto-publish.md 5~6절). 배포를 출처마다 따로 하지 않는다.
6. 송파구 메일 라벨(Label_14 '뉴스더힐-처리') 붙이기, 브라우저 탭 닫기, 보고.

## 1. 공통 규칙
- 필자 `author: 뉴스더힐 편집국`. `time`은 실제 게시 시각(현재보다 뒤로 두지 않음). slug 번호는 그날 마지막 번호 다음부터 출처 순서대로 이어서 붙인다.
- 세 출처 사이 같은 소식(예: 송파구와 경기도가 같은 행사)이 있으면 한 건만 쓴다. `articles/`에 이미 있는 내용은 쓰지 않는다.
- 한 회차 전체 최대 12건. 넘치면 식품 안전(회수) → 송파구 → 식품·유통 → 경기도 순으로 우선.
- Claude in Chrome은 "되면 쓰는" 선택 사항. 없으면 각 문서의 브라우저 없는 방법(Gmail 커넥터, WebFetch, 자체 카드 docs/news-card-style.md)으로 진행하고, 원문 그대로 확인 못 한 문장은 인용하지 않는다. 식약처 PDF를 못 읽으면 그 건은 건너뛴다.
- 한 출처에서 막혀도(사이트 접속 실패 등) 나머지 출처는 계속한다. 막힌 출처는 보고에 적는다.
- 검증에서 판단이 서지 않는 건은 게시하지 않는다(`draft: true`로만 올리고 보고).
