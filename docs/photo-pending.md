# 사진 교체 대기 목록

송파구 자동 게시에서 Chrome 없이 인포그래픽으로 먼저 올린 기사. Chrome이 되는 회차에 송파구 제공 사진으로 바꾸고 줄을 지운다(docs/songpa-auto-publish.md 3-0).

## 식품(식약처·농식품부) 사진 찾기 대기

식품 자동 게시 회차에서 Chrome이나 식약처 누리집 접속이 되면, 새 기사보다 먼저 아래 기사의 대표 사진을 찾는다. 식약처 **보도자료 글에 첨부된 현장 사진**만 쓴다(docs/food-auto-publish.md 이미지 규칙 1·2). 찾으면 사진을 `static/img/<기사번호>-photo1.jpg`로 넣어 본문 맨 위 대표 이미지로 쓰고, 지금 있는 카드는 지정한 단락 위로 옮겨 본문 일정표로 남긴다. 캡션 `*… 사진=식품의약품안전처 제공*`, 기사 끝 출처 문장에 "사진은 식품의약품안전처가 보도자료와 함께 제공한 것"을 덧붙이고 줄을 지운다. 찾아봤는데 첨부 사진이 없으면 줄을 지우고 보고에 "첨부 사진 없음"이라고 적는다(카드는 그대로 둔다).
