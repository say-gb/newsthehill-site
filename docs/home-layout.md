# 첫 화면(홈) 편집 규칙

처음 작성 2026-10-28. 교수님 지시: "사진은 그대로 두더라도, 보이는 걸 나 말고 다른 병원장 인터뷰를 올리고 송파구 소식을 헤드라인으로".

## front matter 표시
- `headline: true` — 첫 화면 큰 헤드라인. 여러 개면 가장 최근 기사.
- `sub: true` — 헤드라인 바로 아래 3칸에 먼저 들어감. 모자라면 최신 사진 기사로 채움.
- `home: false` — 헤드라인·아래 3칸·포토뉴스에서 뺌. 교수님 본인 인터뷰·기고처럼 신문이 개인 매체로 보일 수 있는 글에 붙인다. 최신기사·섹션 목록에는 그대로 나온다.
- `headline`·`sub`는 기사 날짜로부터 **이틀까지만** 유효. 지나면 자동으로 최신순으로 돌아간다.

## 자동 게시·손 게시 기본값
- 교수님 본인이 주인공이거나 필자인 인터뷰·기고(칼럼 박스 밖으로 나오는 글)는 `home: false`를 붙인다.
- 헤드라인은 송파구 등 지역 소식을 우선한다. 교수님이 지정하면 그 기사에 `headline: true`.
