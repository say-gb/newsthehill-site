# 첫 화면(홈) 편집 규칙

처음 작성 2026-10-28. 교수님 지시: "보이는 걸 나 말고 다른 병원장 인터뷰를 올리고 송파구 소식을 헤드라인으로", "아직은 공신력 있는 송파 관장·병원장, 그리고 송파 소식이 유명하지 나는 유명하지가 않잖아".

## 고르는 순서 (build.py home_selection)
- **헤드라인**: `headline: true`(기사 날짜로부터 이틀 유효) → 없으면 최근 사흘 안 송파구 소식(사회·문화, 제목·부제에 '송파', 사진 있음) → 없으면 최신 사진 기사.
- **아래 3칸**: `sub: 1`·`sub: 2`·`sub: 3`(숫자 순, 기한 없음 — 직접 내릴 때까지) → 최근 송파구 소식 → 최신 사진 기사.
- `home: false`: 헤드라인·아래 3칸·포토뉴스에서 뺀다. 최신기사·섹션 목록에는 그대로 나온다.
